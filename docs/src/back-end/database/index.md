# 数据库专题查阅

这里用来查数据库细节。如果刚开始学后端，先按 [主线课程](/back-end/frontend-backend-guide/index) 阅读；在 [任务数据建模](/back-end/frontend-backend-guide/10-sql-and-indexes) 中写过基本 SQL 后，再按需要查下面的专题。
